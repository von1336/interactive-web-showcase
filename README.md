## Detailed Production Breakdown

### 00. Master Launchpad Portal (`index.html`)
- **Direct Link:** [https://von1336.github.io/interactive-web-showcase/](https://von1336.github.io/interactive-web-showcase/)
- **Concept:** Central navigation station presenting all five productions with live status indicators, technology specifications, and responsive preview banners.
- **Key Features:**
  - Keyboard navigation: press keys `1` through `5` to launch individual sites directly; `ESC` returns to top.
  - High-resolution photographic cards with thematic overlays and custom vector SVG badges.
  - Backdrop blur effects, fluid typography scales, and CSS hover physics.

## Engineering Standards

- **Zero Build Dependencies:** Every production runs natively in modern browsers with no Webpack, Vite, or npm compilation steps.
- **Pure Modern Standards:** Clean HTML5 semantics, modern CSS3 (Grid, Flexbox, Variables), and vanilla ES6+ JavaScript.
- **Visual Hygiene:** 100% vector SVG iconography and authorized Unsplash CDN photography. Zero informal emojis across all files.
- **Responsive Geometry:** Tested across mobile, tablet, and desktop viewports with fluid `clamp()` typographic scaling.

## Local Execution

Clone the repository and open `index.html` directly in any browser:

```bash
git clone https://github.com/von1336/interactive-web-showcase.git
cd interactive-web-showcase
```

Run locally with any standard HTTP server:

```bash
# Python
python -m http.server 8000

# Node.js
npx serve .
```

Visit `http://localhost:8000` to launch the central portal.
